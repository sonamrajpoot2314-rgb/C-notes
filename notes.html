C Language Notes

Variables

In C programming language, the term variable is used for holding different types of input data which is provided by the user. It is used to store information. Its value can be modified and reused several times. It is an important method that is used to represent memory location through symbols so that it can be easily identified.

Example Code


#include
int main() {
    int a = 10;//here a is variable int a is declaration and 10 is initialization.
    printf("%d", a);//%d is format specifier.
}
